# CAR-SERVICE — Multi-Project Workspace

Thư mục `car-service/` là không gian làm việc tổng hợp (Multi-Repository / Multi-Source Workspace) chứa nhiều dự án & thành phần mã nguồn độc lập trong hệ sinh thái dịch vụ ô tô.

## Danh sách các Source Code

| Thư mục | Vai trò | Công nghệ | Trạng thái |
| :--- | :--- | :--- | :--- |
| [`autora-web/`](./autora-web) | Website Thương mại Điện tử Dịch vụ Ô tô **AUTORA** (Storefront, Tìm Garage, Giỏ dịch vụ, Đặt lịch, Sổ bảo dưỡng) | Next.js 16, TypeScript, Tailwind CSS v4 | Đã hoàn thiện & Build sạch |
| *(Dự kiến bổ sung)* | Backend API / Partner Portal / Admin / Mobile App | — | Chờ tích hợp |

## Chạy nhanh `autora-web`

```bash
cd autora-web
pnpm dev
```
